Лицензия разрешает личное и коммерческое использование, изменение программы, распространение копий, продажу сборок и платную поддержку. Локальные изменения для собственного использования не требуют публичного репозитория.

При передаче изменённой программы сохраняйте лицензию и существующие уведомления об авторских правах, указывайте изменения и их дату. Получатели сборки должны иметь доступ к полным соответствующим исходникам по правилам раздела 6. Исходники должны соответствовать передаваемой версии и включать необходимые материалы сборки и установки.

Если изменённая версия доступна пользователям через сеть, раздел 13 требует заметно предложить им бесплатное получение соответствующих исходников. Публичный репозиторий с точной версией и заметной ссылкой в интерфейсе может служить способом исполнения этого условия.

Получатели сохраняют право менять и распространять программу. Дополнительное соглашение не может запретить им права, предоставленные AGPL. Для распространения производной программы с закрытым исходным кодом потребуется отдельное разрешение соответствующих правообладателей.

Обычная рукопись не становится AGPL только потому, что её написали с помощью InkOS. Рукописи, пользовательские данные и реальные ключи API не входят автоматически в исходный код программы. Условия поставщика модели и права на исходные литературные материалы рассматриваются отдельно.
