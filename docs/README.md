## Что входит в исходный проект

В репозитории есть три пакета TypeScript: `packages/core` с исполнительным контуром и состоянием, `packages/cli` с CLI/TUI и `packages/studio` с веб-интерфейсом и локальным API. Отдельно хранятся тесты, скрипты сборки и упаковки, примеры настроек, схемы и снимки интерфейса в `assets/`, а также сценарии GitHub Actions.

Встроены 20 навыков модели и 18 справочных файлов. Вместе с `skills/SKILL.md` это рабочие инструкции, используемые самой моделью. В этом выпуске они сохранены в исходном виде; перевод документации для людей их не изменяет.

Исходный `LICENSE` сохранён дословно. Команды, имена файлов, ключи JSON/YAML, идентификаторы навыков, URL и контрольные суммы в переводах сохраняют техническое значение.
