# Повторное использование контекста чата

Заметки по большой истории сохраняются в `.inkos/context-cache/`. При следующем запросе InkOS проверяет хеши уже обработанных сообщений и добавляет новые сообщения без повторного сжатия, пока они помещаются в бюджет модели. Кеш привязан к проекту, сеансу, профилю и произведению. Смена модели сама по себе его не сбрасывает.

Заметки служат справочной памятью. Подтверждения действий, результаты инструментов и текущее состояние произведения программа проверяет отдельно. Изменение старых сообщений, повреждение кеша или нехватка места для новых сообщений требуют повторной подготовки контекста. Исходный журнал сохраняется полностью.

Отдельно сохраняются успешные части сжатия. После ошибки следующая попытка может продолжить с готовых частей. Для одного сеанса хранятся не более 32 частей общим размером до 2 МиБ. Файл общих заметок также ограничен 2 МиБ; в нём остаются хеши сообщений и текст заметок. Кеш записывается атомарно. Ошибка его записи не прерывает пользовательскую задачу.

Регрессионные проверки охватывают пересоздание агента, смену протокола модели, изоляцию проектов и сеансов, исправление старого сообщения, повреждённый кеш и повтор после пустого ответа провайдера. В проверке большого чата второй короткий вопрос после пересоздания агента не вызывает модель для сжатия истории.

Журнал читается построчно, без отдельной строки и массива строк для всего файла. В однократном локальном замере журнала около 72 МБ RSS после восстановления составил 301 МиБ до изменения и 257 МиБ после. Процессорное время чтения составило 3,4 и 3,9 секунды соответственно: этот замер не подтверждает ускорение по CPU. Повторные чтения и проверка полного журнала по-прежнему требуют локальных ресурсов. Сокращение числа обращений к модели проверяется отдельно от нагрузки браузера и сервера.
